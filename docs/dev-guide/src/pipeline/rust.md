# Rust compilation stage

- `prusti_driver` registers callbacks and calls the Rust compiler.
- The compiler expands all [procedural macros](../macros.md), which includes the specifications.
- The compiler does the type-checking.
- Prusti's last callback collects the specifications and starts the verification; three other callbacks run earlier.

In this stage, the actual Rust compiler is invoked to make sure the given code is valid Rust code, both syntactically and semantically. Prusti integrates with the Rust compiler using [`rustc_driver`](https://rustc-dev-guide.rust-lang.org/rustc-driver/intro.html). This allows running the Rust compiler with [callbacks](https://doc.rust-lang.org/nightly/nightly-rustc/rustc_driver_impl/trait.Callbacks.html) triggered at important stages of processing. Prusti implements four of them:

 - [`prusti/src/callbacks.rs` - `PrustiCompilerCalls::config`](https://github.com/prusti/prusti/blob/main/prusti/src/callbacks.rs) - before the compilation starts, Prusti replaces the compiler's `mir_borrowck` query with one that also stores the MIR bodies, together with their borrow-checker facts, for the [Prusti processing stage](prusti.md). It also turns off incremental compilation, since the query is not run again for bodies that did not change.
 - [`prusti/src/callbacks.rs` - `PrustiCompilerCalls::after_crate_root_parsing`](https://github.com/prusti/prusti/blob/main/prusti/src/callbacks.rs) - adds an `extern crate prusti_contracts;` item unless the crate already has one, so that the default extern specifications of `prusti-contracts` (e.g. those of the standard library) are loaded even if the program does not use the crate itself. This only happens when `prusti_contracts` is passed with `--extern`, as `prusti-rustc` does.
 - [`prusti/src/callbacks.rs` - `PrustiCompilerCalls::after_expansion`](https://github.com/prusti/prusti/blob/main/prusti/src/callbacks.rs) - warns if the crate uses the 2015 edition, which Prusti specifications do not support, and with the [`print_desugared_specs`](../config/flags.md#print_desugared_specs) flag, prints the Rust AST after the Prusti specifications are processed, which is useful for debugging and unit testing.
 - [`prusti/src/callbacks.rs` - `PrustiCompilerCalls::after_analysis`](https://github.com/prusti/prusti/blob/main/prusti/src/callbacks.rs) - once the type checking is done and the code is determined to be type safe (code that is syntactically invalid or has type errors is not relevant for Prusti applications), checks and collects the specifications, imports and exports the specifications shared between crates, and, unless verification is turned off, starts the [Prusti processing stage](prusti.md). Unless the [`full_compilation`](../config/flags.md#full_compilation) flag is set, the compilation stops after this callback.
